## 二、引言

### 2.1 研究背景与意义

同时定位与建图（SLAM）是机器人与三维视觉的核心问题。前馈（feed-forward）SLAM 范式用大模型一次前向输出位姿与深度，绕开在线优化，代表了 SLAM 发展的重要方向。但该范式存在两个被忽视的脆弱点：回环判定只依赖外观相似度，实例身份在单视角语义下不可靠。本项目针对这两点展开，具有明确的科学意义与应用价值。

### 2.2 研究目标

| 层次 | 目标 |
| --- | --- |
| 系统层 | 构建纯单目前馈 + 开放词汇 + 全局一致几何的语义稠密 SLAM 系统 |
| 贡献层 | 提出并验证两项技术贡献 |
| 交付层 | 产出可投稿 SCI 中文源稿 + 代码 + 图片 + 报告 |

### 2.3 考核指标

## 三、研究现状

前馈 SLAM（VGGT-SLAM 为代表）在轨迹精度上已接近经典方法，但其回环判定仍停留于外观相似度（SALAD 检索 + αmatch），缺乏超越外观的判据。开放词汇分割（SAM 系列）为语义 SLAM 提供了摆脱闭集类别的可能，但单视角语义的可靠性边界未被量化。语义 SLAM 竞品（2511.16282）在 VGGT 上引入语义身份，但几何为漂移 Sim(3)、语义为闭集。本项目在全局一致几何、开放词汇、可靠性量化、语义回环过滤四个方面形成差异化。

## 四、研究方法

### 4.1 系统架构

V3DSAM 三阶段流水线：VGGT-SLAM 前馈位姿前端（逐字官方）→ SAM3 开放词汇语义分割 → 3DGS 稠密重建。前端不改动，创新点聚焦语义与重建环节。

### 4.2 贡献 1：语义-几何三维一致性回环校验

四步度量：反投影 → 位姿变换 → 重投影比对 → 双向对称平均（阈值 τ=0.10），辅以物体级一致性（τ≈0.25）正交加固。核心机制：假回环（180° 朝向翻转）语义点云重投影后镜像错位，双向一致率极低。

### 4.3 贡献 2：几何锚定的持久实例身份

类别身份 = 语义，实例身份 = 几何。实例 ID 由 3D 几何聚类（voxel 0.02 m、eps 0.05 m）锚定，语义仅切边界，回环靠世界坐标空间重叠识别同一物体。

### 4.4 关键技术决策

| 决策 | 内容 | 理由 |
| --- | --- | --- |
| 前端逐字官方 | 不改 VGGT-SLAM | 精度非瓶颈，聚焦创新点 |
| 外观 L2 定性 | 循环论证（非"分不开"） | 检索分数本身 |
| 类别/实例分工 | 类别=语义、实例=几何 | 语义切边界、几何定身份 |
| 回环真值 | SE(3) 朝向差 | 位置差分不开真假 |
| NVS 定性 | 结构性负结果 | 前馈无外部度量锚 |

### 6.2 关键技术转折

1. **外观 L2 从"分不开"到"循环论证"**：外观 L2 就是检索分数本身，用它判真假是循环论证。
2. **类别/实例身份分工定稿**：从"身份靠几何不靠语义"到"类别=语义、实例=几何"。
3. **重跑 stage1 拿 αmatch**：AlphaCapture 包装 VGGT，为 ScanNet 提取 αmatch。
4. **NVS 负结果结构性定性**：前馈无外部度量锚，负结果是结构性的。

### 6.3 遇到的问题与解决

| 问题 | 解决 |
| --- | --- |
| Splat-SLAM CUDA 架构不匹配（SM_120 vs 4090 SM_89） | 重编 simple-knn/diff-gaussian/lietorch |
| vggt 库 import 失败 | PYTHONPATH 技巧 |
| AutoDL 国际下载慢 | aria2c -x4 |
| ScanNet 语义 id 是 raw id | tsv 映射到 NYU40 |
| ScanNet npz 两套坐标帧 | est_after 位姿正向投影 |
| SAM3 固定 200 query 重复 mask | 一次 50 类替代循环 |
| ScanNet αmatch 缺失 | 重跑 stage1 + AlphaCapture |

## 十、存在的问题与建议

### 10.1 存在的问题

1. 7-Scenes 补充实验未完成（原始 RGB 已删、磁盘 93% 满）。
2. 重建 NVS 无增益（blob 塌缩，尺度对齐与深度监督无效）。
3. 罕见类语义精度偏低（mIoU 0.119，结构类 0.5–0.87）。

### 10.2 原因分析

- 7-Scenes：数据管理不善，属工程问题。
- 重建塌缩：前馈无外部度量锚，结构性负结果。
- 罕见类：开放词汇分割对长尾类别覆盖不足。

### 10.3 建议

1. 若审稿人要求，重新下载 7-Scenes 数据补实验。
2. 以 ScanNet 长序列为 PSNR 测试床验证回环校验对渲染质量的影响。
3. 探索长尾类别处理，提升罕见类 mIoU。
4. 投稿时转英文并补相关工作文献。
