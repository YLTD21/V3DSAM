## 一、引言

### 1.1 研究背景

同时定位与建图（Simultaneous Localization and Mapping，SLAM）是机器人导航、增强现实与三维重建的基石问题。经典 SLAM 系统（ORB-SLAM、DSO、VINS 等）依赖特征点匹配、光束法平差（Bundle Adjustment）与回环检测，精度高但对场景纹理、光照与运动模式敏感，工程复杂度高。

近年来，前馈（feed-forward）SLAM 范式提供了全新路径：用一个大模型一次前向直接输出位姿与深度，彻底绕开在线优化与回环后端训练。其中 VGGT-SLAM 作为代表工作，已在 TUM-RGBD 上取得与经典方法相当甚至更优的轨迹精度（9 个 fr1 序列平均 ATE 0.041）。

### 1.2 前馈 SLAM 的两个脆弱点

尽管前馈 SLAM 简洁强大，但存在两个被普遍忽视的脆弱点，构成本项目的出发点。

**脆弱点一：回环判定只依赖外观相似度。** 前馈 SLAM 的回环候选由外观检索（SALAD 嵌入的 L2 距离）与图像匹配比率 αmatch 共同判定。然而在"同一房间·反向视角"场景中，假回环（相机 180° 朝向翻转）与真回环在位置（差 0.2–1.3 m）、外观（假 0.947 vs 真 ≤0.935）、类别级 Jaccard 三个层面都难以区分。更致命的是：外观 L2 距离本身就是回环检索的分数，检索已按它排序，再用它判真假构成循环论证；而 αmatch 的原生拒绝阈值（−0.95）会全数接受假回环（FP=4）。

**脆弱点二：实例身份在单视角语义下不可靠。** 开放词汇分割（SAM3）给出的逐帧掩码在逐点一致性上仅约 51%，细粒度类低至 16%–36%。更关键的是，语义错标是视角一致的系统性错误——同一物体在所有视角下都被稳定标错，多视角投票无法纠正（对象级多数投票置信度 0.481 vs 逐点 0.51）。这导致"同一条椅子在不同帧被当成不同物体"的身份歧义。

### 1.3 本文贡献

本文构建 V3DSAM 系统（VGGT-SLAM + SAM3 + 3DGS），并针对上述两个脆弱点提出两项技术贡献：

1. **语义-几何三维一致性回环校验**：将 SAM3 类别掩码反投影到三维，用回环候选相对位姿双向对称地逐像素比对语义标签（阈值 τ=0.10），辅以物体级一致性正交加固。在 15 个回环候选（11 真 + 4 假）上实现零误判，判别余量约 2×。
2. **几何锚定的持久实例身份**：实例 ID 由 SL(4) 全局一致世界坐标的几何聚类锚定，语义仅切边界。三方重识别中几何优先达 89.5%/86.6%（room/360），显著优于类别门控 59.2%/52.2% 与外观匹配 2.6%/1.5%。

### 1.4 本报告结构

第二节综述国内外研究现状；第三节详细阐述研究方法（系统架构与两项关键技术的数学表述、算法步骤、参数）；第四节给出实验设置与结果；第五节讨论局限性与负结果；第六节总结。

## 二、研究现状

### 2.1 前馈 SLAM

传统 SLAM 依赖在线优化。VGGT-SLAM 等前馈方法用深度网络直接回归位姿与深度，绕开在线优化。其核心组件包括：前馈位姿/深度估计网络（VGGT）、基于外观检索的回环检测（SALAD 嵌入 + 图像匹配比率）。前馈方法的优势在于无需在线训练、推理速度快，但其回环判定仍停留在外观层面。

### 2.2 开放词汇语义分割

SAM 系列将分割从闭集推广到开放词汇：任意文本 prompt 即可分割任意类别。SAM3 是该系列的最新版本，本项目使用它提供类别掩码。开放词汇语义为语义 SLAM 提供了摆脱固定类别闭集的可能。

### 2.3 3D Gaussian Splatting 与稠密 SLAM

3DGS 以高斯椭球体表征场景，支持高质量实时新视角合成。Splat-SLAM 等将其引入 SLAM 后端做稠密重建。但稠密重建在纯前馈设定下（无在线优化、无外部度量锚）仍面临过拟合与塌缩的挑战。

### 2.4 语义 SLAM 与实例身份

语义 SLAM 将语义标签融入地图。竞品工作 2511.16282（Dinya）在 VGGT 上引入语义身份，但其几何为漂移的 Sim(3)、语义为闭集、未量化单视角语义可靠性。本项目的差异化在于：SL(4) 全局一致几何 + 回环校验、开放词汇、单视角可靠性量化、语义回环过滤。

### 2.5 研究空白

现有工作存在三方面空白：(1) 前馈 SLAM 的回环判定缺乏超越外观的判据；(2) 实例身份缺乏稳定锚定，语义投票在系统性错误下失效；(3) 单视角语义的可靠性边界未被量化。本文针对这三点展开。

## 三、研究方法

### 3.1 系统总体架构

V3DSAM 是三阶段级联流水线，纯单目前馈，无在线优化：

```
图像序列 {I_t}
   │
   ▼
[Stage 1] VGGT-SLAM 前馈位姿前端（逐字官方）
   · 前馈估计相对/绝对位姿 T_t、深度 D_t、内参 K_t
   · 回环候选：SALAD 外观检索 + αmatch 判定
   → 位姿图 + 深度 + 内参 + 回环候选
   │
   ▼
[Stage 2] SAM3 开放词汇语义分割
   · 对关键帧输出类别掩码 M^(c)
   · 掩码反投影到世界坐标 → 语义点云
   → 逐帧语义图 + 语义点云
   │
   ▼
[贡献1] 语义-几何三维一致性回环校验
   · ① 反投影 ② 位姿变换 ③ 重投影比对 ④ 双向对称
   → 校验后的回环约束（喂回位姿图）
   │
   ▼
[Stage 3] 3DGS 稠密重建（Splat-SLAM 后端）
   · 以校验后位姿/深度初始化高斯地图
   · [贡献2] 几何聚类锚定持久实例身份
   → 稠密高斯地图 + 渲染视图 + 实例身份
```

**设计原则**：前端不改动（逐字官方），创新点聚焦语义与重建环节；类别身份由语义给出，实例身份由几何锚定。

### 3.2 前端：VGGT-SLAM 前馈位姿估计

#### 3.2.1 定位与输出

Stage 1 是 VGGT-SLAM 官方实现的逐字拷贝（含 scale_solver），本项目不改前端，仅消费其输出：相对/绝对位姿 T_t、深度 D_t、内参 K_t、回环候选。

#### 3.2.2 回环候选产生机制

回环检测分两步，涉及两个必须严格区分的分数：

**第一步：外观检索（SALAD）。** 对查询帧计算 SALAD 嵌入，检索返回 L2 距离最小的候选帧：

```
score = ‖ embedding − query_vector ‖₂     （越小越相似）
```

该 score 即 similarity_score，原生接受阈值 lc_thres=0.95。

**第二步：αmatch 判定。** 对候选帧对调用 model(lc_frames, compute_similarity=True)，返回 image_match_ratio（αmatch），当 αmatch < −0.95 时拒绝。

#### 3.2.3 两个分数的关键区别

| 分数 | 字段 | 语义 | 阈值 | 判别器角色 |
| --- | --- | --- | --- | --- |
| similarity_score | score | SALAD L2 距离 | < 0.95 接受 | 外观列（b），循环论证源 |
| image_match_ratio | alpha | αmatch 官方判据 | < −0.95 拒绝 | αmatch 列（a），官方方法 |

**关键洞察**：similarity_score 是检索分数本身，用它判真假是循环论证。这是稿件"外观 L2 循环论证"表述的技术依据。

#### 3.2.4 ScanNet αmatch 提取

ScanNet 的 loop_log.json 原本不含 αmatch。为此实现 AlphaCapture 包装 VGGT，重跑 stage1（仅回环检测，不跑 SAM3、不导出 npz）：

```python
class AlphaCapture:
    """每次 compute_similarity=True 记录 image_match_ratio（αmatch）。"""
    def __init__(self, model):
        self._m = model
        self.alphas = []

    def __call__(self, *a, **k):
        out = self._m(*a, **k)
        if k.get("compute_similarity", False):
            self.alphas.append(float(out["image_match_ratio"]))
        return out

    def __getattr__(self, n):
        return getattr(self._m, n)
```

max_loops=1 保证每个被接受的回环恰好触发一次 compute_similarity，故 alphas 与 detected_loops 一一对应。结果：12/7/4/8 = 31 回环，0 失配。

#### 3.2.5 前端精度基线

9 个 fr1 序列平均 ATE 0.041（VGGT-SLAM 2.0 口径）。

### 3.3 语义：SAM3 开放词汇分割与语义点云

#### 3.3.1 语义分割

对关键帧用 SAM3 输出开放词汇类别掩码 M^(c)。关键帧选择由前端决定，语义图记为 labels_all（K × H × W）。

#### 3.3.2 语义点云反投影

将类别掩码反投影到世界坐标，形成语义点云 P_s（pts + label + prompts）。反投影利用前端的深度 D 与位姿 T：

```
P_s = π⁻¹(M, D, K, T)     # 反投影到世界坐标
```

#### 3.3.3 工程细节

- **重复 mask 问题**：SAM3 固定 200 query 会在同一物体产生重复 mask，改"一次 50 类"替代循环。
- **raw id 映射**：ScanNet 语义 PNG 存 raw id（1~1357 稀疏），须经 tsv 映射到 NYU40；误当 0~39 致 mIoU 假负 0.03。
- **坐标帧一致**：npz 中 pts_gs 是 SLAM 世界帧，w2c/depth 是 VGGT 原始帧（尺度差 ~0.45 m），语义须用 est_after 位姿正向投影赋到 pts_gs。

#### 3.3.4 语义可靠性量化

| 指标 | 值 |
| --- | --- |
| 单视角逐点一致性 | ≈ 51% |
| 细粒度类一致性 | 16%–36% |
| 对象级多数投票置信度 | 0.481（vs 逐点 0.51） |

语义错标是视角一致的系统性错误，多视角投票救不回，这直接引出贡献 2 的几何锚定方案。

### 3.4 贡献 1：语义-几何三维一致性回环校验

#### 3.4.1 问题形式化

给定回环候选 (I_i, I_j, T_ij)（T_ij 为候选相对位姿），需判定该候选是真回环还是假回环。真回环指 I_i 与 I_j 观察同一场景区域且朝向一致；假回环指外观相似但几何朝向相反（如 180° 翻转）。

现有判据的失效原因：

- 外观 L2：是检索分数本身（循环论证）；
- αmatch 原生阈值 −0.95：全数接受假回环（FP=4）；
- 类别 Jaccard：真假回环类别集合交叠（假回环同房间同类别）；
- 纯几何深度残差：深度噪声导致真假交叠。

#### 3.4.2 度量定义

对候选 T_ij，定义语义-几何三维一致性 c(i,j)：

**步骤 1（反投影）**：帧 I_i 的类别掩码反投影到世界坐标，得语义点云 P_s。

**步骤 2（位姿变换）**：用 T_ij 将 P_s 变换到帧 I_j 坐标系：

```
P_s→j = T_ij · P_s
```

**步骤 3（重投影比对）**：用 K_j 重投影，逐像素比对语义标签与 I_j 的 SAM3 标签：

```
cons(i→j) = |{ p : label(π_j(p)) == M_j(π_j(p)) }| / |{ p }|
```

其中 π_j 为重投影算子。

**步骤 4（双向对称平均）**：

```
c(i,j) = ½ ( cons(i→j) + cons(j→i) )
```

**判定**：c(i,j) ≥ τ = 0.10 判真，否则判假。

#### 3.4.3 物体级一致性（正交加固）

除逐像素一致率外，另设物体级一致性 match_ratio（阈值 τ_obj ≈ 0.25）。逐像素度量与物体级度量正交：前者捕捉空间对齐，后者捕捉物体身份对齐。两者结合进一步压低假正例。实验显示物体级度量单独最优阈值 0.371 也能 P=1.0/R=1.0。

#### 3.4.4 分离原理

- **真回环**：同一场景同一朝向，语义点云在三维空间真实重合，双向重投影一致率高。
- **假回环**（180° 朝向翻转）：外观相似但几何朝向相反，语义点云重投影后镜像错位，双向一致率极低。

语义-几何联合的本质：语义给出"是什么"，几何给出"在哪、朝哪"，两者必须同时在三维空间对上才算真回环。

#### 3.4.5 算法伪代码

```
输入：回环候选 (I_i, I_j, T_ij)、语义点云 P_s、掩码 M_i/M_j、内参 K_i/K_j
输出：c(i,j) 与判定

function verify_loop(I_i, I_j, T_ij):
    P_proj = project(transform(P_s, T_ij), K_j)     # 反投影+变换+重投影
    cons_ij = mean(label(P_proj) == M_j(P_proj))
    P_proj = project(transform(P_s, T_ij⁻¹), K_i)
    cons_ji = mean(label(P_proj) == M_i(P_proj))
    c = 0.5 * (cons_ij + cons_ji)                   # 双向对称平均
    match = object_level_match(M_i, M_j, T_ij)       # 物体级一致性
    return c, match, (c >= 0.10) and (match >= 0.25)
```

### 3.5 贡献 2：几何锚定的持久实例身份

#### 3.5.1 问题形式化

单视角开放词汇分割不可靠（逐点一致性 51%），且语义错标是视角一致的系统性错误。因此实例身份（"是哪一把椅子"）不能靠语义投票。

#### 3.5.2 核心表述

| 身份维度 | 由谁给出 | 理由 |
| --- | --- | --- |
| 类别身份（是什么） | 语义（SAM3） | 语义天然回答"是什么" |
| 实例身份（是哪一把） | 几何（世界坐标聚类） | 世界坐标稳定、跨视角一致 |

**步骤 5：回环重识别。** 回环时靠世界坐标空间重叠（质心距离/空间重合）认出同一物体。

#### 3.5.4 SE(3) 真回环选帧

持久实例矩阵的"回环帧"必须选真回环（位置 + 朝向都近），避免选到假回环（同一位置反向视角，跨房间）。用 SE(3) 约束（位置差 < 0.6 m，朝向差 < 35°）选帧：

```python
def _rot_angle(R):
    c = (np.trace(R) - 1.0) / 2.0
    return float(np.arccos(np.clip(c, -1.0, 1.0)))
```

#### 3.5.5 持久实例判定

持久实例 = 在局部帧中可见 ≥2 且回环帧可见 ≥1 的实例。选帧时按质心可见的持久实例数打分，清晰度（Laplacian 方差）做 tiebreaker。

### 3.6 后端：3DGS 稠密重建

#### 3.6.1 初始化

以校验后的位姿与深度初始化高斯地图（stage3 输入 npz），用 Splat-SLAM 后端做稠密重建。

#### 3.6.2 重建塌缩根因

重建出现 blob 塌缩，根因定位为 final_refine 无正则化的 RGB 过拟合：

| 尝试 | 结果 |
| --- | --- |
| 尺度对齐 | 无效 |
| 深度监督 | 无效 |
| 语义边界门控 opacity decay | 负（浮点在语义内部，非边界） |
| 梯度感知 opacity decay（StereoGS） | 唯一有效杠杆（内置但被关闭） |

#### 3.6.3 负结果定性

NVS 无增益是前馈范式的结构性负结果：所有已有"修复"都靠外部度量锚/几何先验/换表征，纯前馈设定下无锚。故重建写为系统贡献/负结果，不写"语义提 PSNR"。

## 四、实验

### 4.1 实验设置

**环境**：AutoDL RTX 4090（SM_89），sgs conda 环境，Python 3.10+ / PyTorch 2.x。

**数据集**：

| 数据集 | 场景 | 用途 |
| --- | --- | --- |
| TUM-RGBD | 9 个 fr1 序列（room/360/desk2/floor/plant/rpy/teddy） | 前端 ATE、回环校验、重识别 |
| ScanNet | 4 场景（scene0000_00/0059_00/0106_00/0207_00） | 长序列回环、mIoU、持久实例 |

**指标**：ATE、P/R、重识别 recall、mIoU、pixel_acc、计算开销。

**超参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| τ | 0.10 | 逐像素一致性阈值 |
| τ_obj | ≈0.25 | 物体级一致性阈值 |
| lc_thres | 0.95 | 外观接受阈值 |
| αmatch 拒绝 | −0.95 | 官方回环判据 |
| submap_size | 32 | ScanNet stage1 子图 |
| min_disparity | 50 | 前端视差过滤 |
| max_loops | 1 | αmatch 1:1 映射 |
| voxel | 0.02 m | 体素下采样 |
| eps | 0.05 m | 聚类邻域 |

### 4.2 回环校验实验

#### 4.2.2 四路消融（最优阈值）

| 判别器 | 阈值 | TP | TN | FP | FN | P | R | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 无校验 | — | 11 | 0 | 4 | 0 | 0.733 | 1.000 | 基线 |
| αmatch 原生 | −0.95 | 11 | 0 | 4 | 0 | 0.733 | 1.000 | 原生阈值失效 |
| 外观 L2 | 0.747 | 11 | 4 | 0 | 0 | 1.000 | 1.000 | 循环论证、过拟合 |

| 物体级 | 0.371 | 11 | 4 | 0 | 0 | 1.000 | 1.000 | 正交加固 |
| **语义-几何 3D（本文）** | **0.10** | **11** | **4** | **0** | **0** | **1.000** | **1.000** | 唯一正交 + 尺度免疫 + 噪声鲁棒 |

**关键洞察**：αmatch 若重新调阈值到 0.98 也能 P=1.0，但原生部署阈值是 −0.95（失效）；外观 L2 在 0.747 阈值 P=1.0，但它是检索分数本身（循环），且阈值过拟合。只有语义-几何三维一致性在"原生设计阈值 0.10"下零误判，无需过拟合调参。

## 五、讨论与局限

### 5.1 重建塌缩（结构性负结果）

NVS 无增益是前馈范式边界，非方法贡献。短序列 ATE/PSNR 解耦（room PSNR 23.86→23.86 不变），ScanNet 长序列是唯一可能的 PSNR 测试床。

### 5.2 罕见类语义精度

mIoU 0.119 中稀有细粒度类拖累整体（结构类 0.5–0.87），开放词汇分割对长尾类别覆盖不足。

### 5.3 7-Scenes 未完成

原始 RGB 已删 + 磁盘 93% 满导致延期；前端 ATE 已跑 22 序列、29 原生回环。

### 5.4 类别重叠指标不一致

TUM 用 Jaccard（|∩|/|∪|），ScanNet 用 min-归一（|∩|/min(|A|,|B|)），已在图注区分，不影响结论。

## 六、结论

本项目构建了纯单目前馈的开放词汇语义稠密 SLAM 系统，提出并验证两项技术：语义-几何三维一致性回环校验（15 候选零误判、ATE 提升 11×）与几何锚定持久实例身份（重识别 89.5%）。全部实验数字真实可查。
